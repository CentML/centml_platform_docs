CCluster is also developed as an open-source project under the Apache 2.0 license at [github.com/NVIDIA/ccluster](https://github.com/NVIDIA/ccluster). It is a Kubernetes-native platform for managing AI workloads across distributed, multi-cloud GPU infrastructure.

<Note>
The open-source project is in an early stage and changes quickly. See the repository README for its current status and scope.
</Note>

## How the project is structured

- **Control-plane operator** — orchestrates the platform. It registers clusters, decides what is deployed where and in what order, and collects status from each cluster in one place.
- **Infra-plane operator** — runs on each workload cluster. It checks that the cluster's dependencies are installed and healthy, and reports back.
- **Catalog** — the Helm charts the control plane deploys, such as the GPU Operator, cert-manager, Istio, and KEDA, along with inference, training, and compute workloads.
